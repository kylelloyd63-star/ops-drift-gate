# Source Family local transfer receipt

The Source Family integration contract is a versioned foundation for linking a SourceInk page to a SourceToMe library record through the existing SourceBridge flow. It is a local provenance receipt, not a network service or an Ops Drift Gate scan. The app-side packet importer and receipt writer are not yet wired into SourceInk or SourceToMe.

## What it records

Version 1 records a transfer ID, UTC timestamp, app versions, SHA-256 hashes, byte counts, and an opaque SourceToMe record reference. It intentionally excludes page content, page titles, filesystem paths, and custody values. The JSON Schema is at `integrations/source-family/transfer-receipt.schema.json`; the Ops Drift Gate package exports a validator and byte verifier from `ops-drift-gate/integrations/source-family`.

Use `exact-copy` only when SourceToMe retains the exact bytes selected in SourceInk. Use `derived` when import or normalization changes the artifact. The verifier checks each supplied artifact against its receipt hash and size; it does not claim that a derived artifact preserves semantic content.

## Trust and limits

- The receipt is unsigned. Hash matching detects disagreement between the receipt and supplied bytes, but does not authenticate who created the receipt or prevent someone from changing both.
- It does not prove that data stayed on-device, that an app made no network request, or that a synthesis is correct.
- A `valid` result means only that the supplied source and destination bytes match this receipt's hashes and sizes.
- The opaque record reference should be generated by SourceToMe, not derived from a title, path, account name, or other identifying text.
- Apps should write and read receipts locally, fail closed on an invalid receipt, and keep transfer optional. Existing SourceBridge transfers must continue to work if receipt creation is unavailable.

## JavaScript API

```js
import {
  createSourceFamilyReceipt,
  verifySourceFamilyReceipt
} from "ops-drift-gate/integrations/source-family";

const receipt = createSourceFamilyReceipt({
  bridgeVersion: "1.0.0",
  sourceVersion: "1.0.0",
  sourceBytes,
  destinationVersion: "1.0.0",
  destinationRecordRef: "local-record-123",
  destinationBytes,
  relation: "exact-copy"
});

const result = verifySourceFamilyReceipt(receipt, {
  sourceBytes,
  destinationBytes
});
```

The helper accepts `Uint8Array` values and hashes them in memory. Apps written in other languages can use the same schema and perform the same SHA-256 and byte-count checks without invoking Node or Ops Drift Gate.
