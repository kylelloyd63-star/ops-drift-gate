# Agent guidance

Before creating or changing any user-facing interface, read the repository-root `DESIGN.md`. It is the canonical Dripstatic Studios identity shared across products. Keep its brand tokens consistent between the design guide and implementation token files; put task-specific composition and behavior in the surface brief.

For the OpsGate browser UI, read `web/DESIGN.md` too; it specifies the product's color balance and task composition.

## Iteration preference

When the user invokes iterative testing, adapt a three-pass cadence to the task: first pass, audit and plan; second pass, audit and plan; third pass, reconcile the results and report recommendations. Do not force extra rounds when the task does not call for them.
